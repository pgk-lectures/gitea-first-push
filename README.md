# Как загрузить проект на GitHub

Эта инструкция поможет впервые загрузить готовый проект с компьютера на GitHub.

Вам не нужно подробно разбираться в Git. Выполняйте действия по порядку и внимательно копируйте команды.

## Что получится в конце

На компьютере останется ваша обычная папка с проектом, а её копия появится в репозитории на GitHub.

После изменения проекта вы сможете снова отправить новую версию на GitHub.

## 1. Зарегистрируйтесь на GitHub

1. Откройте сайт [github.com](https://github.com/).
2. Нажмите **Sign up**.
3. Укажите свою электронную почту.
4. Придумайте пароль.
5. Придумайте имя пользователя. Оно будет видно другим людям.
6. Подтвердите электронную почту по письму от GitHub.
7. Войдите в созданный аккаунт.

Запомните электронную почту, которую использовали при регистрации. Она может понадобиться при первой настройке Git.

## 2. Убедитесь, что Git установлен

Откройте терминал и выполните:

```bash
git --version
```

Если появился номер версии, например:

```text
git version 2.51.0
```

значит Git установлен и можно продолжать.

Если появилось сообщение, что команда `git` не найдена, скачайте Git с сайта [git-scm.com/download/win](https://git-scm.com/download/win), установите его с обычными настройками и перезапустите Visual Studio.

## 3. При необходимости укажите своё имя и почту

Эти команды обычно требуется выполнить только один раз на компьютере:

```bash
git config --global user.name "Ваше имя"
git config --global user.email "Ваша почта GitHub"
```

Пример:

```bash
git config --global user.name "Ivan Ivanov"
git config --global user.email "ivan@example.com"
```

Вместо данных из примера укажите свои данные.

## 4. Создайте пустой репозиторий на GitHub

Репозиторий — это место на GitHub, где будут храниться файлы проекта.

1. Откройте [github.com](https://github.com/).
2. В правом верхнем углу нажмите кнопку **+**.
3. Выберите **New repository**.
4. В поле **Repository name** напишите название проекта.
5. Выберите видимость:
   - **Public** — репозиторий виден всем;
   - **Private** — репозиторий виден только вам и приглашённым пользователям.
6. Не включайте **Add a README file**.
7. Не добавляйте `.gitignore` и лицензию.
8. Нажмите **Create repository**.

После создания откроется страница пустого репозитория.

## 5. Скопируйте адрес репозитория

На странице репозитория найдите поле **Quick setup** и выберите **HTTPS**.

Адрес будет выглядеть примерно так:

```text
https://github.com/username/project-name.git
```

Нажмите кнопку копирования справа от адреса.

У каждого репозитория свой адрес. Не копируйте адрес из примера.

## 6. Откройте терминал в папке проекта

Команды должны выполняться именно в папке, где находится ваш проект.

В Visual Studio:

1. Откройте проект.
2. В верхнем меню выберите **Вид → Терминал**.
3. Посмотрите на путь перед курсором и убедитесь, что терминал открыт в папке проекта.

Можно использовать и Проводник Windows:

1. Откройте папку проекта.
2. Щёлкните правой кнопкой мыши по свободному месту.
3. Выберите **Открыть в терминале**.

## 7. Создайте локальный репозиторий

Выполните:

```bash
git init
```

Git начнёт следить за изменениями файлов в этой папке.

Файлы проекта никуда не переместятся и не удалятся.

## 8. Добавьте файлы проекта

Выполните:

```bash
git add .
```

Точка в конце команды означает: добавить все файлы из текущей папки.

Между `add` и точкой должен быть пробел.

## 9. Сохраните первую версию

Выполните:

```bash
git commit -m "init"
```

Коммит — это сохранённая версия проекта.

Текст после `-m` является коротким описанием версии. Вместо `init` можно написать, например:

```bash
git commit -m "Добавил готовый проект"
```

Сообщение нельзя оставлять пустым.

## 10. Назовите основную ветку main

Выполните:

```bash
git branch -M main
```

Эта команда задаёт основной ветке стандартное имя `main`.

## 11. Свяжите папку с репозиторием на GitHub

Выполните команду, подставив скопированный адрес своего репозитория:

```bash
git remote add origin https://github.com/username/project-name.git
```

Например, если пользователь называется `student` и репозиторий называется `shoe-store`, команда будет такой:

```bash
git remote add origin https://github.com/student/shoe-store.git
```

Не используйте этот пример без изменений. В команде должен быть адрес именно вашего репозитория.

## 12. Отправьте проект на GitHub

Выполните:

```bash
git push -u origin main
```

При первой отправке GitHub может открыть окно браузера и попросить войти в аккаунт. Войдите в тот аккаунт, в котором создали репозиторий, и подтвердите доступ.

Обычный пароль от GitHub нельзя вводить в терминал вместо специального токена. На учебном компьютере проще пройти авторизацию через открывшееся окно браузера.

## Все основные команды вместе

Выполняйте их по одной, а не вставляйте всё одной строкой:

```bash
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/username/project-name.git
git push -u origin main
```

В пятой команде обязательно замените пример на адрес своего репозитория.

## 13. Проверьте результат

1. Вернитесь на страницу репозитория в браузере.
2. Обновите страницу.
3. Убедитесь, что на странице появились файлы и папки проекта.

Если файлы появились, проект успешно загружен.

## Как отправить изменения в следующий раз

После изменения проекта не нужно снова выполнять `git init`, менять ветку или добавлять `origin`.

Откройте терминал в папке проекта и выполните только:

```bash
git add .
git commit -m "Кратко опишите изменения"
git push
```

Пример:

```bash
git add .
git commit -m "Добавил форму авторизации"
git push
```

## Частые ошибки

### Команда git не найдена

Git не установлен или Visual Studio не была перезапущена после установки.

Установите Git, закройте Visual Studio и откройте её снова.

### Please tell me who you are

Git не знает имя или почту автора. Выполните:

```bash
git config --global user.name "Ваше имя"
git config --global user.email "Ваша почта GitHub"
```

После этого снова выполните команду `git commit`.

### Remote origin already exists

Связь с удалённым репозиторием уже была добавлена. Повторно выполнять `git remote add origin` не нужно.

Проверьте сохранённый адрес:

```bash
git remote -v
```

### Repository not found

Проверьте три вещи:

- адрес репозитория скопирован полностью;
- репозиторий существует;
- выполнен вход в правильный аккаунт GitHub.

### Файлы не появились на GitHub

Убедитесь, что команда `git push` завершилась без ошибки. После отправки обновите страницу репозитория в браузере.

## Коротко: что делает каждая команда

| Команда | Что она делает |
| --- | --- |
| `git init` | Включает Git в текущей папке |
| `git add .` | Подготавливает все файлы к сохранению |
| `git commit -m "init"` | Сохраняет первую версию проекта |
| `git branch -M main` | Называет основную ветку `main` |
| `git remote add origin ...` | Связывает папку с репозиторием GitHub |
| `git push -u origin main` | Первый раз отправляет проект на GitHub |
| `git push` | Отправляет следующие версии проекта |
